Racing game that runs in the terminal with unique controls. 
Utilizes a Zybo Zynq-7000 along with four Pmods (2x ALS, 1x MAXSONAR, 1x OLED). 
-ALS sensors are used for steering in between lanes.
-MAXSONAR is used as a score multiplier whenever you cover it.
-OLED displays game info (highscore, current score, time).
*Hoping to display to external monitor off the Zybo at a future date.
